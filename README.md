# pongbot

Forberedt version af pong enginen i arbejdede med, læs migrerings filen for mere information.

## Kør

```bash
npm start
```

Åbn den URL, terminalen skriver, typisk [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

Hvis 8080 er optaget, tager den næste ledige port. I Firefox: brug `127.0.0.1` hvis `localhost` ikke virker.
